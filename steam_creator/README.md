# 🎮 Steam Account Creator v1.0

Автоматизированная консольная программа для **Windows 11**, которая:

- регистрирует временные почтовые ящики на **firstmail.ltd**;
- автоматически создаёт аккаунты **Steam**;
- подключается к **VPN** (бесплатные конфиги **VPN Gate**) для смены страны/IP;
- генерирует уникальные логины и пароли;
- сохраняет результаты в текстовые файлы.

> ⚠️ **Важно о легальности.**
> Массовая автоматическая регистрация аккаунтов нарушает
> [Пользовательское соглашение Steam (SSA)](https://store.steampowered.com/subscriber_agreement/)
> и правила многих сервисов. Используйте программу только в образовательных,
> тестовых целях и на собственных данных. Автор не несёт ответственности за
> блокировку аккаунтов, IP или другие последствия. Капча — самое слабое место
> решения без платных сервисов; она может не пройти автоматически.

---

## ✅ Требования

- **Windows 11** (подойдёт Windows 10/11)
- **Python 3.10 или новее** ([python.org/downloads](https://www.python.org/downloads/))
  - при установке отметьте галочку **«Add Python to PATH»**
- Стабильный интернет
- Установщик **OpenVPN** (программа скачает и установит автоматически)

---

## 📦 Как установить зависимости

Автоматически (рекомендуется):
Программа сама проверит и установит OpenVPN и Python-пакеты при первом запуске.

Вручную:

```bash
pip install -r requirements.txt
```

В `requirements.txt` указаны:
- `DrissionPage` — управление браузером (анти-детект);
- `requests` — HTTP-запросы (VPN Gate, проверка IP);
- `undetected-chromedriver` — драйвер Chrome с обходом детекта.

---

## 🚀 Как запустить

```bash
cd steam_creator
python main.py
```

При запуске программа:

1. Проверит версию Python (нужна 3.10+);
2. Установит недостающие Python-пакеты;
3. Проверит OpenVPN (при отсутствии скачает с официального сайта и тихо установит через `/S`);
4. Покажет баннер и спросит **регион** (Россия 🇷🇺 / Украина 🇺🇦 / Казахстан 🇰🇿);
5. Спросит **количество аккаунтов**;
6. Начнёт цикл создания: **VPN → почта firstmail → аккаунт Steam**.

Во время работы:
- VPN подключается один раз на сессию к выбранному региону;
- каждый аккаунт получает уникальные логин и пароль;
- между действиями выдерживаются случайные задержки (анти-бан).

## 📁 Выходные файлы

| Файл            | Описание |
|-----------------|----------|
| `accounts.txt`  | Созданные аккаунты. Формат: `логин_steam-пароль_steam-логин_почты-пароль_почты`. Записываются **в конце** сессии (не перезаписываются). |
| `errors.txt`    | Ошибки с временем. Записываются **в реальном времени**. |
| `app.log`       | Подробный лог работы (DEBUG в консоль, INFO в файл). |
| `.chrome_profile/` | Профиль браузера DrissionPage (создаётся автоматически). |

Пример строки `accounts.txt`:
```
darkwolf47-mkpqt8834ls-darkwolf47-xrvbn44219q
firetiger823-coldsteel991-firetiger823-hunter4421k
```

## 🛠 Важные примечания

- **Капча.** Сайты постоянно меняют защиту. Если капча не пройдена за 3 попытки —
  аккаунт пропускается, ошибка пишется в `errors.txt`.
- **Селекторы.** В модулях `firstmail.py` и `steam_reg.py` используются CSS/текстовые
  селекторы. Если сайты поменяют вёрстку — их нужно обновить вручную.
- **VPN Gate** — публичный и бесплатный сервис; серверы могут быть перегружены.
  При неудаче программа перебирает следующий сервер из списка.
- **Прерывание.** По `Ctrl+C` программа корректно сохраняет накопленные аккаунты
  и отключает VPN.
- **Кодировка.** Все файлы — UTF-8. Консоль автоматически переводится в UTF-8,
  чтобы кириллица отображалась корректно.
- Все пути в проекте относительные — папку можно перенести целиком.

## ⚠️ Ограничения

Программа использует реальные сайты (`firstmail.ltd`, `store.steampowered.com`,
`vpngate.net`). Возможны:
- блокировки IP со стороны Steam/FirstMail;
- смена вёрстки сайтов (ломает селекторы);
- невозможность автоматического прохождения сложной капчи.

Никаких платных API не используется.
